AmigaAMP-Isometric v1.0c
======================

Build environment:
- MSYS on Windows
- AmigaGCC / m68k-amigaos-gcc in PATH

Compile:

cd /pfad/zum/ordner/AmigaAMP-Isometric
make clean
make

If your AmigaGCC setup does not support -noixemul, remove -noixemul from CFLAGS and LDFLAGS in the Makefile.

Result:
- AmigaAMP-Isometric

Install / use:
- Copy the binary to your AmigaAMP plugins/tools location
- Start it while AmigaAMP is already running
- The plugin opens a borderless fullscreen window on the current Workbench/Public Screen
- It uses the active RTG/Picasso96 Workbench resolution automatically
- ESC or Ctrl-C exits the plugin

Visualizer details:
- Isometric 16x16 tower field
- 16 frequency bands across the X axis
- 16 history slices into the Z/depth axis
- colour ramp from blue to green to yellow/orange/red
- top centered metadata lines, without visible plugin header title
- binary-visible credit string:
  AmigaAmp Isometric by Andreas 'Andiweli' Stuermer

Final v1.0 font order:
- Tahoma
- Verdana
- TrebuchetMS
- Arial

For these fonts:
- line 1 size 18
- line 2+ size 16

Fallback:
- NewTopaz 8 / 8 / 8
- TOPAZ/topaz.font 8 / 8 / 8
